# Agent 与协作执行设计

## 1. 目标

这一层对应 Claude Code 的：

- AgentTool
- runAgent
- coordinator mode
- worktree isolation

## 2. 角色

### 2.1 主 agent

负责：

- 与用户对话
- 调度工具
- 决定是否派生子代理

### 2.2 worker agent

负责：

- 执行受限任务
- 汇报结果
- 在隔离上下文中运行

### 2.3 coordinator

负责：

- 多 worker 调度
- 结果汇总
- 与用户通信

## 3. 核心能力

### 3.1 spawn

启动一个子代理执行独立任务。

### 3.2 send

向已有子代理发送后续指令。

### 3.3 wait

等待一个或多个子代理完成。

### 3.4 stop

中止错误方向上的子代理。

## 4. worktree

当任务有文件写入风险时，可为 worker 创建独立 worktree。

目标：

- 降低冲突
- 支持隔离实现
- 避免主工作区被子代理直接污染

## 5. 后台任务

子代理应支持后台运行，并通过任务通知返回完成状态。

## 6. 设计约束

1. 子代理不应天然拥有主代理的所有 UI 能力。
2. 子代理执行必须受权限系统和上下文隔离控制。
3. 多代理协作是进阶能力，不进入 MVP。
